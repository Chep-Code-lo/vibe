# 04. UI/UX Checklist

## 1) UI tiêu chuẩn
- Bố cục nhất quán: 8px spacing system.
- Typography: tối đa 2 font family.
- Màu sắc theo semantic token (primary/success/warning/error).
- Tất cả component có trạng thái: default/hover/focus/disabled/loading.

## 2) UX bắt buộc
- Luôn có phản hồi hệ thống:
  - Loading skeleton.
  - Toast thành công/thất bại.
  - Empty state có CTA.
- Form có validate realtime.
- Hỗ trợ keyboard navigation.

## 3) Responsive
- Breakpoints: 360, 768, 1024, 1280.
- Bảng thống kê có chế độ card ở mobile.

## 4) Màn hình MVP
- Landing + CTA.
- Login/Register/Forgot password.
- Topic list.
- Quiz player.
- Result analysis.
- Dashboard cá nhân.
- Admin question manager.

## 5) Accessibility
- Tối thiểu WCAG AA cho contrast.
- ARIA label cho biểu đồ/chức năng chính.
