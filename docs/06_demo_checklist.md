# 06. Demo & Tự chấm theo rubric

## A. Checklist demo trước buổi chấm
- [ ] Tạo tài khoản student/teacher/admin.
- [ ] Student làm quiz hoàn chỉnh.
- [ ] Hiển thị phân tích lỗi theo taxonomy.
- [ ] Dashboard cá nhân có biểu đồ và dữ liệu thật.
- [ ] Teacher xem thống kê lớp.
- [ ] Admin CRUD câu hỏi + xem audit log.
- [ ] Kiểm thử lỗi: token hết hạn, nhập sai mật khẩu, submit trùng.

## B. Mapping rubric -> bằng chứng
1. UI/UX: video responsive + link Figma + design tokens.
2. Logic ứng dụng: sơ đồ state + luồng session.
3. Backend/API: openapi + Postman collection.
4. Database: ERD + migration + index list.
5. Security: report OWASP checklist.
6. Performance: k6 benchmark + screenshot metrics.
7. Mở rộng: autoscaling config + cache hit rate.
8. Phân tích theo dõi: dashboard product analytics.
9. Vận hành: pipeline CI/CD + backup policy.
10. Chiến lược sản phẩm: roadmap 3 tháng + KPI.

## C. Thang tự chấm nhanh
- 90-100: đủ toàn bộ checklist + benchmark + xử lý tình huống demo.
- 75-89: đủ chức năng chính, thiếu một phần observability hoặc hardening.
- <75: logic chưa ổn định, demo dễ lỗi, thiếu chứng cứ kỹ thuật.
